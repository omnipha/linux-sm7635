# BOOT.md (historical pointer)

This file used to accumulate every boot and session log (5,900+ lines). Its
sections now live unchanged as individual records in [records/](records/),
with `source: BOOT.md` in their front matter.

Read instead:

- [status.yaml](status.yaml) - current measured state, one next question
- [PLAN.md](PLAN.md) - ordered next steps, one active issue
- [INDEX.md](INDEX.md) - generated map of all records

New measurements: create a new dated file in `records/`; never edit this file
or an existing record. See `omnipha/agents` `docs/records-and-lean-files.md`.
